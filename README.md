# JoinGuard

Telegram moderation bot that greets new members, enforces a 30-minute non-link verification, auto-kicks obvious spam, and maintains admin action logs and reports.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
